- 模块
  - 新增：`authn/sm2`（`rbs-core`），职责「SM2/SM3 的 JWS 验签、`r||s` 编码、SM2 公钥解析（PEM/JWK→PEM）」，不承担算法分派/claims/公钥查找（§8）。
  - 修改：`authn/common`、`authn/bearer_token`、`authn/token`(AttestTokenVerifier)、`authn/jwks`、`admin/key`、`tools::token`（§8）。

  - 层级：工具层 `tools`/`rbc`、服务层 `rbs-rest`、核心层 `rbs-core`（§2.2、§10）。
- 接口
  - 外部依赖：GTA REST API（`GET /challenge`、`POST /attest`，§3.1）；GTA 验签公钥资料（PEM 文件 / JWKS 文件，§3.2）。
  - 对外接口：`Authorization: Bearer/Attest <JWT>`（§4.1）；`POST /rbs/v0/users`、`PUT /rbs/v0/users/{username}`（§4.2）；`rbs-cli token gen --alg SM2`（§4.3，含 `--export-private-key`）。
  - 涉敏接口标记（密码学）：`rbs-cli token gen`（携带 SM2 私钥/口令，§4.3.2）；`--export-private-key`（导出 SM2 私钥，§4.3.2，行 1131）。
- 数据
  - `t_user_info`：`auth_value`(SM2 公钥 PEM)、`auth_alg`(新增取值 `SM2`)，无 DDL 变更（§2.3.1）。
  - 敏感参数：SM2 私钥（rbs-cli 本地）、私钥口令、导出的 SM2 私钥（§4.3.2）。
- 状态
  - 认证 token 类型：`Bearer`/`Attest`（§2.1）；算法白名单 `PS256/PS384/PS512/EdDSA/SM2`（§6.4）。
  - 密钥生命周期：仅 attestation JWKS 支持多键轮换（§2.3.2/§5.5），用户 SM2 密钥无生命周期状态设计。
- 配置
  - `auth.attest_token.public_key_path`、`auth.attest_token.jwks_file`（§3.2、§5.4）；`rest.rate_limit`（§4.1.5）。

  - SM2 验签 P99 < 10ms；Bearer 端到端新增 < 15ms；Attest < 12ms；rbs-cli 生成 < 100ms；≥500 QPS/worker（§6.1）。
